# Profile Image Setup

To add your professional photo to the About section:

1. Add your image file to the `public` folder
2. Name it `profile.jpg` (or update the import path in AboutSection.tsx)
3. Recommended specifications:
   - Square aspect ratio (e.g., 800x800px)
   - Professional headshot or portrait
   - High quality JPEG or PNG
   - File size: under 500KB (Next.js will optimize it)

The component will automatically display your image once added.
Until then, a placeholder will be shown.
