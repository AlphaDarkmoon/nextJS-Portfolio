# Python Icon

Place your `python.png` file in this directory.

The decorative Python icon in the Skills section will display once the image is added.

**Recommended specifications:**
- PNG format with transparent background
- Size: 512x512px or larger (Next.js will optimize it)
- Python logo (official or similar)
- Clean, recognizable icon

You can download the official Python logo from:
https://www.python.org/community/logos/

The icon will appear with:
- Low opacity (8% light mode, 12% dark mode)
- Bottom-right corner positioning
- Slight overflow effect
- No interaction
- Purely decorative
